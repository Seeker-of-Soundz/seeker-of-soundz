# Seeker Of SoundZ v7.0.88 — Socials layout and custom icon picker

- Admin Socials Manager: editable labels, names, descriptions, URLs, order, visibility, and new icon preset picker plus HTTPS icon image URL input and preview.
- Public Socials: image icons supported, card icons separated from text, flexible content layout, responsive wrap on small screens.
- Run `supabase/patch-v7.0.88-custom-social-icons.sql` in Supabase SQL Editor to allow icon URLs longer than eight characters. Existing records are not deleted.
- Host custom icons on a trusted HTTPS image host or your own website; direct image links must end in PNG/JPG/WebP/GIF/SVG. SVG is allowed as an image URL, but use only trusted sources.
- Browser and production Supabase integration tests not performed.
